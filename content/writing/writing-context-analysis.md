# 写作情境分析小笔记

写作前先判断**写作情境**，避免一上来就堆内容。写作不是单纯“把东西写出来”，而是根据任务、读者和目的，组织材料与证据。

### 1. 任务：我要完成什么？

先明确交付物是什么。

常见问题：

```text
我要写的是论文、报告、proposal、邮件、笔记、slides，还是说明文档？
这次写作要解决什么具体任务？
有没有字数、格式、截止时间、评分标准？
```

### 2. 题材：我要写什么对象？

题材是写作的内容对象。

例如：

```text
一篇论文
一个研究想法
一次实验
一个城市案例
一种方法
一次会议记录
一个项目进展
```

题材决定材料范围。题材太散，文章就会失焦。

### 3. 目的：我想让读者获得什么？

目的决定写法。

常见目的：

```text
说明：让读者理解一件事
说服：让读者接受一个观点
汇报：让读者知道进展与问题
申请：让读者相信我值得支持
评价：判断某个方案好坏
记录：为之后复盘留下证据
```

写作前要能说清一句话：

```text
我希望读者读完后，相信/理解/决定/记住什么？
```

### 4. 读者：谁会读？

读者决定语言深度、背景铺垫和证据要求。

需要判断：

```text
读者是导师、同学、评审、公众，还是未来的自己？
他们懂多少背景？
他们最关心问题、方法、结果，还是可行性？
他们可能质疑什么？
```

同一个内容，写给导师要突出问题和决策点；写给评审要突出 gap、贡献和证据；写给自己要突出过程、失败和下一步。

### 5. 体裁：应该按什么规范写？

体裁决定结构。

例如：

```text
论文：问题 → 文献 → gap → 方法 → 实验 → 结论
proposal：背景 → 问题 → 方法 → 计划 → 风险
组会汇报：进展 → 卡点 → 证据 → 需要反馈
笔记：概念 → 判断 → 例子 → 可复用模板
```

不要用一种体裁写所有东西。论文式写法不适合会议纪要，笔记式写法也不适合投稿论文。

### 6. 调研 / 实验：证据从哪里来？

写作不能只靠观点，需要证据。

调研型写作关注：

```text
已有文献怎么定义问题？
有哪些方法流派？
现有研究解决了什么，没解决什么？
我的判断有没有来源？
```

实验型写作关注：

```text
数据是什么？
方法如何执行？
结果是否可复现？
有没有 baseline、指标、失败案例？
结论是否超过证据？
```

### 7. 展示：如何让内容被看懂？

展示不是美化，而是降低理解成本。

需要考虑：

```text
标题是否直接？
段落是否有中心句？
图表是否比文字更清楚？
是否需要流程图、矩阵表、对比表、案例图？
读者能否在 1 分钟内抓住主线？
```

## 最小检查模板

```text
写作任务：
题材对象：
写作目的：
目标读者：
采用体裁：
需要调研/实验的证据：
最终展示形式：
读者读完后应获得的结论：
```

一句话总结：

> 写作情境分析，就是先判断“为谁、为了什么、用什么证据、按什么体裁、展示什么结论”，再开始写。
